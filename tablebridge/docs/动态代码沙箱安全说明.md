# 动态清洗代码执行安全说明

动态清洗代码来自模型或人工编辑，均按不可信输入处理。应用不执行任意 Python；以受限语法和表格能力限制动态代码，再叠加子进程超时、资源和输入输出上限。该方案服务于本机单人表格转换，不能宣称为允许任意 Pandas 的通用容器沙箱。

## 代码能力边界

`sandbox.py` 使用 `ast.parse` 和白名单解释器，不调用 `eval` 或 `exec`。仅允许单变量赋值、标量字面量、列表、字典和公开表格函数调用。拒绝 import、自定义函数、循环、推导式、属性访问、索引、运算表达式、私有名字、解包调用、文件函数和任意函数。变量不能覆盖公开函数，变量使用前必须已经定义。

内部 `_refs`、`_before`、`_errors`、`_types` 和 `_id` 由可信函数维护，源表和目标表不能使用下划线开头的字段。代码没有读取环境、文件路径、凭据或网络的函数。文件中的提示文本只作为数据。文本替换为字面操作；目标格式模式只允许预定义手机号、数字文本和邮箱模式，不能输入任意正则。

AST 限制 16000 字符、3000 节点、100 条语句和 20 层表达式嵌套，单文本常量最长 2000 字符。公开表格函数校验列、数据类型和行数。非法代码在启动子进程前就被拒绝。

## 进程与资源

源码启动通过 `python -I sandbox.py` 启动工作进程；打包后通过同一 EXE 的 `--sandbox-worker` 入口。工作进程使用独立临时目录，只从 stdin 接收当前表格和代码，从 stdout 返回 JSON。环境只保留系统运行所需的少量变量，不传入 API Key、模型配置、Python 路径或其他应用凭据。

父进程限制运行 12 秒，超时后终止并回收子进程。工作进程在支持 `resource` 的平台限制 CPU 8 秒、地址空间 768 MiB。Windows Python 不提供此模块，因此 Windows 当前只有解释器能力限制、数据上限及父进程超时，没有操作系统级内存配额。此差异已明确，不能把 macOS/Linux 的配额验证描述为 Windows 保障。

输入单文件 10 MiB，XLSX 解压体积 50 MiB，每份表最多 5000 条、60 列，合并最多 10000 条；工作进程输入/输出 JSON 上限 24 MiB。输出通过增量编码检查上限后才返回。进程异常、超时、无效 JSON 或代码校验失败均使当前运行失效，不保留旧预览作为可导出结果。

## 文件及导出

XLSX 拒绝宏、外部链接、合并单元格、空或重复表头。源行公式/Excel 错误进入待人工处理清单，不以缓存值参与转换；XLS 公式检测后整文件拒绝。表头公式或 Excel 错误直接拒绝。目标模板数据区必须为空，不覆盖历史业务数据。

工号保留文本，不推断前导零；金额用 Decimal，拒绝不明确千分位、非有限值、超出 Excel 15 位有效数字或绝对值 1e12 的数值。文本写入 XLSX 时强制字符串类型；XLS 字符串由 xlwt 以文本写入。CSV 的危险文本首字符前增加单引号，并保留原业务值在 JSON 审计中。CSV 采用严格编码，不能编码时阻止导出。

导出必须经过异常处理门禁和回读检查。XLS 使用 xlwt 输出 OLE/BIFF8，xlrd 回读确认，未将 XLSX 改后缀伪装成 XLS。所有格式验证目标表头原序、行数、文本内容和数值。每次运行独立目录，不覆盖已生成快照。

## 服务和数据

HTTP 只监听 127.0.0.1，验证 Host 和 Origin，拒绝跨站请求。静态文件路径为固定清单，下载路径仅接受运行 UUID 和固定文件名。GUI 对文件数据和模型文本进行 HTML 转义，配置凭据仅留服务端。

该服务没有企业级用户鉴权或静态数据加密；本机其他程序仍可能访问回环端口与用户可读数据。审计可能包含完整员工信息。正常生产运行应由用户管理本机目录访问权和数据留存，Windows EXE 及 WebView2 仍需真实目标环境验收。

如果未来开放任意 Python/Pandas，必须采用独立受限账户、文件与网络隔离、系统级内存配额等更强边界，不能仅扩大当前 AST 白名单后宣称同等安全。
