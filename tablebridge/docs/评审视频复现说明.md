# 评审视频复现说明

2026-10-12 更新的评审视频为约 3 分 03 秒的通用转换工作台演示，位于提交材料中的 `表桥_演示视频.mp4`，另附解说词、SRT 字幕、视频验收报告和视频实测导出成果。

视频按业务问题、输入文件、描述要求、核对执行、检查结果、处理异常、导出、保存复用展开，使用真实浏览器连续操作帧。模拟员工数据来自 `samples/universal/`。录制时本机服务使用 8878 端口；默认启动端口为 8877，可按 README 修改。

手动依次上传 `系统A_员工报销.xlsx`、`系统B_员工费用.csv` 和空白 `目标HR_员工导入.xlsx`，展开源字段。按视频写明转换要求与日期、冲突、异常业务口径，点击“用模型生成转换流程”。本版实际调用 DeepSeek 并显示返回的清洗代码，未载入静态演示。请求模型为 deepseek-chat，实际响应模型为 deepseek-flash。模型请求等待压缩约 1 秒，其余操作按真实连续帧呈现。

核对目标约束并执行：7 条源数据，排除 1 条负金额，去掉 1 条完全重复，输出 5 条；1 个含字母的手机号导致暂停导出。工号 0004 在本虚构案例中的核实号码是 `13800138001`，选择修正并提交，问题数变为 0。选择 XLS，生成、回读验证并下载。保存流程后点击复用；视频展示载入成功，新文件的重新计算与再次校验见通用验收记录和测试。

视频实际下载的 XLS 是 BIFF8，5 条数据、8 列；首条工号为文本 `0001`、日期 `20260115`、金额数值 1250.5（界面显示 1250.50）。结果 ZIP 包含 `import.xls`、`audit.json`、`workflow.py`。视频的 CSV 部分展示编码选择，没有将 XLS 下载冒充 CSV 导出；四种 CSV 编码的既有实测见 `通用转换验收记录.md`。

本视频不代表正式 HR/ERP 已成功导入，也不代表 Windows 原生桌面或 EXE 已实机验收。当前包保留早期人事场景申报书作为申报底稿，最新通用版本范围以 README、通用验收记录、本视频及提交材料的版本说明为准。
